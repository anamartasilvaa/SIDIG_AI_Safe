### SIDIS – Mode B (Docker)

Only the gateways and the RabbitMQ consoles are published; services, Keycloak and databases are on the internal network.
The passwords are **random** and live in `infrastructure/.env` (generated by `docker/gen-certs.ps1`, never committed).

| What | Link | User / Password |
|:-----|:-----|:----------------|
| API Gateway 1 / 2 | [https://localhost:8443](https://localhost:8443) / [https://localhost:8444](https://localhost:8444) | Keycloak token (users below) |
| Keycloak (login/token only) | [https://localhost:8443/realms/aisafe](https://localhost:8443/realms/aisafe) – the gateway only proxies `/realms/`; the admin console is not exposed in Mode B | admin: `KC_ADMIN_USER` / `KC_ADMIN_PASSWORD` in `.env` |
| RabbitMQ management (nodes 1, 2, 3) | [http://localhost:15672](http://localhost:15672), [15673](http://localhost:15673), [15674](http://localhost:15674) | `RABBITMQ_USER` / `RABBITMQ_PASSWORD` in `.env` |
